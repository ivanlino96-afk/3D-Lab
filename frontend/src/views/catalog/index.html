Antes de cotizar

Preguntas frecuentes

Lo esencial para enviar tu proyecto con confianza.

¿Cuánto tarda una cotización?

Revisamos cada solicitud de manera individual. Un asesor te contactará para confirmar factibilidad, costo y tiempo estimado de fabricación.

¿Qué archivos puedo enviar?

Actualmente aceptamos hasta 20 archivos STL por solicitud, con un máximo combinado de 500 MB.

¿Pueden ayudarme si todavía no tengo un modelo 3D?

Sí. Podemos evaluar tu idea, pieza física o necesidad para ofrecer diseño de piezas o ingeniería inversa.

¿Cómo elijo el material correcto?

Puedes consultar nuestra guía. Si tienes dudas, revisaremos el uso, esfuerzo, temperatura y acabado que requiere la pieza.

¿Cómo se realiza el pago?

El pago se acuerda directamente con el asesor después de aprobar la cotización; no se procesa dentro de esta plataforma.

¿Qué sucede con mis archivos STL?

Solo el administrador puede consultarlos. Los archivos válidos se conservan durante 30 días y después se eliminan.
